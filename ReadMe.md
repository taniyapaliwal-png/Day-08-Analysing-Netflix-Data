# 🎬 Netflix Data Analysis

A beginner-friendly data analysis project exploring a Netflix dataset using **Python, Pandas, and Matplotlib**.

## 📌 Project Overview

This project explores Netflix titles to understand patterns in:

* Release years
* User ratings
* Content ratings
* Highly rated titles
* Number of titles released over time

The project was created as a hands-on exercise while learning data analysis and data visualization with Python.

## 🛠️ Tools & Libraries

* Python
* Pandas
* Matplotlib
* Jupyter Notebook

## 📊 Analysis & Visualizations

The project includes:

1. **User Rating Distribution** — explores how user ratings are distributed.
2. **Titles by Release Year** — compares the number of titles across different release years.
3. **Top 10 Rated Titles** — identifies the highest-rated titles in the dataset.
4. **Titles by Rating Category** — examines the distribution of content ratings.
5. **Release-Year Trend** — visualizes how the number of titles changes across years.

## 🔍 Key Insights

The analysis explores differences in release patterns, user ratings, and content-rating categories within the dataset.

The visualizations make it easier to identify patterns that are less obvious when looking at the raw data.
